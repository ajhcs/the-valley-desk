# MCP Registry entry (optional)

`server.json` is a draft entry for the public MCP Registry, which is in preview. Publishing it is optional and is an owner step: it needs the registry's publisher tool and proof of control of `thevalleydesk.org` (DNS or HTTP), because the name uses the `org.thevalleydesk/` namespace. Nothing has been published.

The same description is served live at `https://thevalleydesk.org/mcp/server-card` as an MCP Server Card (SEP-2127).
