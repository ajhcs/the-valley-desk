## Validation receipt

The final release-gate JSON is generated outside the repository after the exact
candidate commit is created. It records the candidate commit/tree and every
command result, avoiding a self-referential receipt inside the commit. Final
handoff must name that SHA and receipt path. Required evidence includes:

- Named end-to-end legislative-change test: official HB HTML produces PN 100 → PN 101 amendment → hearing history, applicability, citations, and an explicit editor blocker.
- Timeliness congestion/jitter test and authenticated attachment-to-persistent-review integration test.
- `npm test`, `npm run ops:smoke`, one `npm run build`, `npm run secret-scan`, `npm audit --audit-level=high`, and artifact verification.
- `npm run backfill:policy:dry-run` with `productionMutation:false` and direct extraction of the actual HIMSS PDF with stable artifact SHA-256.
