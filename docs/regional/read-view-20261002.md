## Data contract and limits

`prepareRegionalSourceReadView` parses the inactive regional inventory, projects configured official news/public leadership registries, and builds coverage from caller-supplied source-health receipts. The process-local prepared token is opaque, immutable and valid for 15 minutes. JSON copies cannot impersonate it. The implementation accepts no source URL or fetch instruction from queries and performs no network, database, model or publication operation.

`queryRegionalSourceReadView(view, request, serverNow)` accepts only optional institution IDs, five allowed channels, four configuration states, a limit of 1–50 and a snapshot/filter-bound cursor. The interface owner must supply trusted server time, rebuild the view after expiry and provide its own authorization, request/response transport, error handling and tool discovery. Caller-controlled time is rejected as a query field. Snapshot freshness is explicitly at `snapshot.asOf`, rather than silently being treated as current forever.

Returned source labels distinguish registry configuration from inactive citation declarations. This adapter does not reread retained source bytes; `evidenceVerifiedByThisAdapter` is always false. Citation URLs, capture timestamps, representation hashes and nullable source publication dates remain distinct. Raw quotes, page HTML, ownership notes, credentials and upstream error text are excluded. Institution names and all other strings remain untrusted data: render them as text, retain attribution, and never execute embedded instructions.

The existing-registry projection includes official news and public leadership only. RSS, existing event adapters and technology source plans remain explicitly unintegrated, even though the new inactive inventory may propose those channels. Missing registrations mean no source in this bounded input for that institution/channel. Channel applicability is unreviewed; do not turn the matrix into a comprehensive-coverage percentage. Counts of accepted publications and people with confirmed current affiliation are unknown (`null`). Registry presence, a listing timestamp, a named roster entry and a fresh empty-source receipt cannot establish those counts.

The explicit actual-fixture test observes 33 institution inventory entries, nine newly proposed sources (six inventory-only, three planned), 127 institution/channel registration gaps and zero fresh sources without supplied health receipts. This does not assert zero real coverage or a production outage. No newly proposed source is configured or active.
