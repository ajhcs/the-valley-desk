## Correspondence and integration contract

Start with the exact revised model hash and enumerate each obligation's assumptions, implementation symbol, storage boundary, test stimulus and expected result. Historical success of 74 SMT lemmas across 32 families proves only the encoded statements. It does not prove source truth, full native semantics or production transactions. Re-run changed mathematical/native checks with pinned tooling and isolated parser caches only during authorized implementation validation. Keep unchanged historical results labeled historical.

Construct an independent oracle for exact query normalization, OR-within/AND-across filters, whole-interval date inclusion, unique-term relevance scoring, integer date keys and stable identity ties. Cover every exposed query kind: works, people, organizations and projects, including alphabetical empty-query creator ordering and match-count-then-name creator ordering. Differentially compare concrete API behavior on generated boundary cases; avoid deriving expected outputs from the function under test. Include creator-only, paper-only and forum-only records, all six routes, unresolved authors, independent provenance and identity collisions.

Exercise real persistence boundaries for uniqueness, replay, restart and full-dependency CAS. Schedule simultaneous publication, evidence/decision replacement, identity correction, relationship withdrawal, policy changes and expiry. Verify ABA prevention and coherent primary reads. A snapshot pins immutable public row revisions and its dependency vector; material invalidation yields 410/restart. P20/P21 partition tests apply to valid snapshots only, never justify serving withdrawn claims.

Inspect script reachability before claiming CI coverage. Current `npm test` and `posttest`/`test:watch-launch` enumerate test files explicitly: adding a file under `test/` does not run it automatically. Append every new discovery suite to the actual executed lists or a required explicit discovery script invoked by CI. Record executed test identities and prove a deliberately failing temporary discovery assertion makes the required job fail, then remove it before final qualification.

Preserve existing locked installation, hash-locked official PDF tools and byte regressions, tests, typecheck/production build, local D1 scheduled smoke, high-severity dependency audit and secret scan. Review prebuild and smoke side effects; use isolated state. Wait for final CI conclusions on the exact candidate SHA, not partial logs.

3. **AC-WP23-03:** Given concurrent dependency/ABA schedules, stale writes fail and invalidated continuations return 410; evidence is real-storage interleaving traces.

4. **AC-WP23-04:** Given a new discovery test, actual CI executes it and the sentinel failure blocks the job; evidence is script mapping and controlled failure/removal receipts.

5. **AC-WP23-05:** Given the final candidate, all retained mandatory checks finish successfully without silent exclusion; evidence is exact-SHA CI conclusions and artifact hashes.
