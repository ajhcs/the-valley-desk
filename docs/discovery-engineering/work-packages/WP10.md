## Implementation and interface contract

1. Implement an independent reviewed work/institution query plan, not enrichment that requires a GitHub URL or PubMed ID. Freeze allowed query/filter names, bounded date windows, page size and total cap with WP06. Record the reported result scope and any provider truncation; no global regional recall claim follows from a keyword query.

2. Normalize DOI according to the WP02 contract, retaining original value, canonical DOI and provider identity separately. Validate DOI URLs before making public links. A repeated DOI is idempotent; contradictory metadata creates another observation and review hold rather than overwriting admitted facts.

3. Parse titles, contributors, affiliations, publication types, date-parts, relationship metadata and license links only from qualified fields. Preserve year/month/day precision and distinct online/print/update dates. Metadata deposited or indexed timestamps must not become publication dates. Missing affiliation is unknown and a matching institution string alone cannot resolve a person.

4. Propose typed relations to versions, corrections, retractions or other identifiers with exact evidence pointers. Do not merge a preprint with a journal article or treat DOI cross-links as independent corroboration. Syndicated PubMed/Crossref descriptions of one origin count once unless independent evidence is established.

5. Return WP06 observations, rejected items and continuation receipts with query/configuration binding. Enforce byte/request/page budgets and parser versions; expired tokens restart a new bounded cohort. License metadata is a candidate artifact-rights claim, distinct from permissions to collect and redisplay metadata. Exercise absent fields and heterogeneous contributors without dropping the whole valid page silently.
