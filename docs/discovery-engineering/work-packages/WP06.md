## Implementation and interface contract

1. Create a strict adapter interface: plan(scope, checkpoint, budget), parse(retainedRepresentation, requestBinding), and nextPage(receipt). Results contain observations/candidate leads, rejected count, terminal/truncation state, typed health and provenance references; none grants publication authority. Register GitHub, PubMed, Crossref, arXiv, forum and institutional routes separately.

2. Bind qualification receipts to installation identity, configuration digest, parser/version, sampled endpoints, rights decision, access decision, expiry and engineering/editorial owners. Keep activation a separate authenticated event. Recheck permission and lease revisions in the same transaction that retains a page.

3. Existing collector deliberately rejects requiresAuth with watch-credential-resolver-not-provisioned; it does not resolve credentials. Add a server-only resolver returning permitted origin/header bindings from a credential reference. Missing/expired credentials produce typed blocked/misconfigured outcomes. Never store secrets in enrollment, URLs, observations, public errors or test receipts.

4. Existing sourceEndpointAllowed compares full URL equality: generated search parameters and unseen pagination URLs currently fail. Define a reviewed endpoint template grammar with exact scheme/host/path, permitted parameter names, value bounds and page-token binding. Do not replace this with host-only access. Revalidate redirects and pagination against that grammar; reject private network destinations and credential forwarding across origins.

5. Reserve request count before every network attempt, including redirects/retries. Bound streamed bytes before retention, wall time, pages and items. Persist backoff/Retry-After and typed failure outcomes. Keep source health, check completeness, last-good evidence and coverage distinct. Document qualification, API/access charges and recurrent operator labor as explicit operating costs.

## Acceptance criteria

- **AC-WP06-01:** Activate a receipt with changed parser/configuration or expired rights; collection remains disabled; retain rejection receipt.

- **AC-WP06-02:** Require a credential with no resolver result; zero unauthorized requests occur and a typed gap appears; retain redacted request audit.

- **AC-WP06-03:** Generate an allowed second-page URL and an extra arbitrary parameter; only the qualified template instance is fetched; retain URL grammar cases.

- **AC-WP06-04:** Redirect to another origin or private address; transport rejects before sensitive headers or a new request leak; retain mock call records.

- **AC-WP06-05:** Race two attempts at the final request/byte allowance; aggregate committed consumption stays within limits; retain transactional counters.

- **AC-WP06-06:** Exercise the shared interface with synthetic representative adapters for all six routes, including success/failure, credentials and pagination; retain contract receipts. Actual permitted provider qualification belongs to WP08–WP13 and WP24; it is not a prerequisite to their implementation.
