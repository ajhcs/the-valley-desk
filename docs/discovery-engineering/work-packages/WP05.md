## Implementation and interface contract

1. Define a representation receipt binding source enrollment/configuration revision, actual endpoint, captured instant, original bytes digest, normalized text digest, normalizer/parser versions and bounded storage location. Separate a later observation of unchanged bytes from a new representation. Never describe UTF-8 re-encoding of text as captured wire bytes.

2. Define exact text spans with UTF-16 offsets or typed structured pointers bound to a representation revision. Validate pointer/value and quote/offset equality before accepting evidence. A claim references specific evidence IDs and digests, not the latest URL content. Restrict full-text retention to approved source rights.

3. Create claim and decision revisions containing subject, predicate, value, uncertainty, temporal interval, evidence vector, policy versions, authority, rationale and superseded decision. Contradictory claims coexist until an authenticated decision selects a supported public value; rejected or withdrawn decisions remain auditable.

4. Assign provenance origin independently of fetch URL. Reprints, syndications and mirrored metadata from one original work contribute one origin unless an adjudicated origin rule establishes independence. Origin merge/split is a new reviewed revision and invalidates affected corroboration decisions.

5. Expose appendRepresentation, appendEvidence and appendDecision with idempotency keys and expected head revisions. Concurrent stale writes abort their whole transaction. Return durable acknowledgment only after committed byte/metadata binding checks; downstream model proposals cannot manufacture an acknowledgment. Store private contact/notes separately from fields eligible for public projection.

## Acceptance criteria

- **AC-WP05-01:** Change one character outside a quoted span; the original evidence still points to its retained revision and the new revision does not replace it; retain both hashes.

- **AC-WP05-02:** Submit an incorrect span or structured pointer/value; evidence acceptance fails atomically; retain negative fixtures and row counts.

- **AC-WP05-03:** Replay unchanged bytes and the same idempotency key; one representation/decision identity remains while observation timing is explicit; retain receipts.

- **AC-WP05-04:** Observe one press release on three mirrors; distinct-origin count remains one; retain origin equivalence ledger.

- **AC-WP05-05:** Record contradictory affiliation claims and a later correction; all revisions remain inspectable while the accepted head changes once; retain decision history.

- **AC-WP05-06:** Fail a refresh; still-permitted evidence survives without renewed healthy/current status. Separately revoke retention permission; reviewed redaction/removal leaves only legally permitted minimal audit metadata and invalidates dependents; retain both state transitions.
