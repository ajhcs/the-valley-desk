## Implementation and interface contract

1. Create strict discriminated schemas for person, organization, provider account, continuing project and work artifact. Accounts use provider plus installation plus native ID; organizations and people retain internal stable IDs and reviewed external aliases. Repository transfers and account renames change aliases, never identity. Separate aliases from adjudicated equivalence; identical display names are insufficient.

2. Define typed attribution, account ownership, affiliation, project membership and artifact-version relations with evidence and decision revision references. Enforce endpoint kinds in application validation and storage constraints. DOI/PMID cross-links propose an equivalence relation; they do not silently collapse publication and preprint records.

3. Add discovery-specific source dates covering instant/day/month/year/unknown, original reported text, evidence references and supported half-open calendar intervals. Existing SourceDate supports only instant/day/unknown; do not fabricate a day or widen its Watch semantics. Freeze timezone and unknown-timezone behavior in WP02 before coding conversion or date filtering.

4. Persist exact county keys for PA Bucks, Chester, Delaware, Montgomery, Philadelphia and NJ Burlington, Camden, Gloucester, Mercer. Distinguish current-local from local-at-creation claims and residence from professional affiliation. Unknown county or unknown current validity never satisfies membership.

5. Create additive tables with explicit foreign keys, composite uniqueness and immutable revision rows plus mutable heads. Provide idempotent writes returning stable IDs and an explicit conflict when the same key has incompatible kind or payload. Keep project grouping optional and license evidence separate from access permission.
