## Implementation and interface contract

1. Create an explicit nonproduction config with unique local storage/bindings, no production database IDs, no cron/network/email dispatch and discovery collection/publication disabled. The current wrangler config contains live bindings and active flags; copying it verbatim is unsafe rehearsal setup. Verify isolation mechanically before opening the database.

2. Hash the migration set, candidate source, fixture, tool versions and baseline row-level invariants. Apply legacy then additive discovery migrations in an isolated local environment; preserve Watch/news tables, IDs, geographic interpretation, routes/feed consumers and historical evidence. Imported discovery leads require new nine-county admission rather than automatic public conversion.

3. Inject failure after every schema/data/publication/checkpoint boundary. Verify actual transactional rollback, resumable migration receipts and idempotent rerun. Existing ops-smoke in-memory batch executes statements sequentially; it cannot demonstrate rollback. Use a real transactional SQLite/D1-local harness and retain implementation-specific behavior separately.

4. Rehearse bounded restart after lost lease, incomplete page chain, pending decision and interrupted publication. Reconcile immutable evidence/revision hashes, heads, generations, invalidation epochs and snapshots. Ordinary process restart preserves valid immutable membership or returns 410. Database restore rotates a recovery incarnation held outside the restored D1 state and binds all new snapshots/cursors to it; every pre-restore cursor returns 410 even when old heads/epochs match. If external recovery state is unavailable, discovery stays closed.

5. Export approved isolated data, restore into a second fresh database and compare identities, evidence bytes/digests, decision lineage, relation endpoints, projections and checkpoints. Keep public discovery closed until post-backup withdrawals, retention removals and permission changes are reconciled from independently retained evidence, or restored claims are requalified; matching restored hashes alone cannot reopen visibility. Measure actual restore time and retained-data loss against thresholds fixed before the exercise; proposed targets need owner approval, not retrospective PASS.

6. Rehearse application rollback with additive tables retained and new routes/flags disabled. Establish whether each migration is backward compatible; an incompatible change needs a forward repair/data-restore plan. Never truncate/drop discovery evidence merely to restore old application behavior. Produce exact-candidate go/hold evidence for WP27 without executing any live cutover.

## Acceptance criteria

- **AC-WP26-01:** Point rehearsal configuration at a production binding or enable network/cron dispatch; preflight refuses execution before writes; retain isolation receipt.

- **AC-WP26-02:** Apply migrations twice to the sanitized legacy fixture; expected schema/results are stable and legacy invariant hashes match; retain before/after dumps.

- **AC-WP26-03:** Fail mid-transaction and restart after each declared crash point; no partial accepted/public state appears and progress is recoverable; retain failure matrix.

- **AC-WP26-04:** Restore into a fresh isolated database; approved snapshot hashes/relational integrity match, then post-backup withdrawal/removal evidence reconciles before reopening discovery; retain both independent comparisons.

- **AC-WP26-05:** Restore a previously revoked claim with its matching old heads/epoch and an old cursor; rotated external incarnation rejects every old cursor with 410, and discovery remains closed until post-backup revocation/removal reconciliation or requalification; retain no-resurrection evidence.

- **AC-WP26-06:** Rollback the application candidate while retaining additive tables; legacy routes/feed fixtures pass and discovery stays disabled; retain compatibility results.

- **AC-WP26-07:** Measure recovery duration/loss against frozen thresholds; any miss is a release hold with an assigned repair, not a qualified restore claim; retain timing/counters.
