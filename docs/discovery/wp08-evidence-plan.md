# WP08 verification plan

Target: the GitHub-only acquisition path from an enrolled, qualified synthetic
source through actual local D1 registry/transport and WP07 atomic collection.
The frozen WP08 criteria and accepted WP06/WP07 trust boundaries govern this work.
No real provider enrollment, source acquisition, scheduler or deployment is part
of this increment. Local implementation acceptance and E04 route qualification
remain separate decisions.

| Criterion | Required observation |
| --- | --- |
| AC-WP08-01 | Empty catalog/paper state; GitHub account/search and repository collection retain native private leads and a real collection receipt, with publicationAuthorized=false. |
| AC-WP08-02 | Rename/transfer preserve the numeric native key; alias and owner changes remain attributable to the corresponding retained body/version. |
| AC-WP08-03 | Same-name account and ambiguous author/contributor do not become a person merge, regional claim or admission; body/path contradictions fail. |
| AC-WP08-04 | Baseline, releases, tags and commits remain distinct. Dates retain source meaning; a moved tag has its target SHA in its version. Lists require a usable retained repository baseline. |
| AC-WP08-05 | Unsolicited 304 and absent/corrupt/wrong baseline fail. Next Link origin/path/query/page must match the enrolled grammar and chain. Forging acquired Link metadata fails its recorded finish digest. |
| AC-WP08-06 | 403 rate-limit hints and 429 record rate-limited with conservative backoff; plain403 is auth-failed;404 remains an unresolved upstream gap. Private/malformed/truncated/inconsistent search cannot become healthy-empty or complete coverage. |

Root's EX11 amendment carries a bounded Link value, including explicit absence,
from transport through its immutable finish digest to provisional parsing and
private receipt payload. Existing optional-field-free acquisitions retain their
old shape; GitHub list parsing requires captured metadata. All newly copied URL
material is owned by the existing page scope and removed with its page payload.
Actual D1 rollback/removal/restart tests requalify the shared composition.

The observer checks attempts, budgets/backoff, retained raw bytes/private leads,
page/checkpoint/health rows and injected egress calls. The test author is Terra,
separate from Sol's adapter implementation. Root independently inspects code,
challenges the seams, runs integrated regressions and records disposition. Test
inputs and logs are hashed; failed and superseded runs remain retained.

Collection is unconditional: no conditional validator is sent, and an unsolicited
304 cannot create a new success or use arbitrary cached bytes. ETag-based refresh
optimization requires separately qualified same-endpoint retained validators.
The local tests do not establish provider access, rights, current regional truth,
semantic parser completeness or live GitHub pagination stability. WP03 and E01–E06
remain empirical obligations; the new adapter does not supply their truth labels.
