# WP09 PubMed verification

The target is the private discovery-owned PubMed path over accepted WP06/WP07
contracts. Search and metadata fetch are different enrolled sources, attempts,
rounds and batch scopes; neither can bypass the other's budgets or receipt.
The frozen WP09 criteria govern the experiments. Live access/rights and E04
source-class qualification remain separate from local implementation acceptance.

| Criterion | Discriminating evidence |
| --- | --- |
| AC-WP09-01 | Empty local D1, a separately qualified synthetic institutional scope, retained ESearch response, and separately budgeted EFetch; raw body, publication lead and actual private page receipt exist without repository/project rows. |
| AC-WP09-02 | Legacy Wistar rejects another institution and changed limits; generalized scope separately checks institution, declared search literal, first-party quote/hash, exact county/state address and window. Test Mercer/NJ and reject New Castle/DE and Maryland namesakes. |
| AC-WP09-03 | Source affiliations remain per author and historical candidates; person IDs and current employment remain unresolved. No matching-name join or regional/public admission is performed. |
| AC-WP09-04 | Unrequested/repeated PMIDs fail; missing requested IDs produce an incomplete batch. A different parent with identical IDs/changed offset or window cannot rebind the durable fetch source. Corrupt/removed parents are unavailable. |
| AC-WP09-05 | Retain year/month/day precision without inventing days; refuse entities, foreign namespaces, unbound prefixes and mixed text that would be reordered. Contact text is redacted in candidate fields, including unknown date literals. |
| AC-WP09-06 | Stop after search, exhaust fetch budget and observe zero sends/complete inventory; restart with same retained search and deterministic fetch ID. Only an explicitly requalified source revision/new budget window and new cohort permits the resumed fetch; prior charges stay intact. |

Use actual isolated local D1 migrations 0001–0044, no environment files or remote
bindings, closed injected egress and synthetic source controls. Observe attempts,
raw bodies, page/lead/health rows, query/window/ID bindings and budget readback.
Sol implements; Terra independently owns the actual-D1 tests; Astra independently
challenges geography, XML, privacy and immutable bindings. Root reruns integration
and records exact before/after hashes, failed attempts and acceptance limits.

The existing Wistar publication suite is added explicitly to the discovery test
command, reducing the recorded omitted legacy test inventory from eleven to ten.
Its old caps and two-request manual transport are compatibility obligations.
Metadata batch completion does not mean the publication search or region is fully
covered. Provider-wide pacing, real source rights, geographic/identity accuracy,
review staffing and empirically measured recall remain qualification work.
