# GL05 Lehigh and Rowan offline source intake

The private metadata-only source assertions preserve source-reported observations for review. They do not authorize publication, establish ownership, count distinct projects or people, establish a worksite, or expand the nine-county DVRPC primary geography. Lehigh is neighboring context.

- Lehigh: 1,442 source rows from the initial and follow-up tables; 15 source files hashed. The initial and follow-up path prefixes distinguish the two passes. The records include 62 initial URLs, 10 initial no-match observations, 2 initial unavailable observations, 278 combined rows, 117 lab-account repository rows, 679 member-account repository rows, 44 publication-review samples, 28 coverage rows, and 5 follow-up unavailable observations. The rows overlap and represent source scope, not a census.
- Rowan: 587 source observations, including 99 matched-repository rows, 57 matched-account rows, 56 account-snapshot rows, 100 screening dispositions, 78 remaining-publication index rows, 100 Europe PMC bibliographic records, one unavailable repository, and the earlier 61-repository/35-snapshot rows. All 21 source files were hashed. The saved 20-file manifest and the first-pass manifest were independently verified against source bytes.

Metadata fields are allowlisted per source file in each manifest. URLs and other retained strings pass through the reviewed Drexel sanitizer; source bodies, descriptions and contact details are excluded. The raw files and historical snapshots remain in their original locations. Reported account affiliation, code ownership, historical associations, external collaborators, failed availability checks and source search limits require review. The source qualifications distinguish Lehigh mixed member-account scope and neighboring geography, and Rowan/CMSRU/Cooper/Coriell partner contexts and uncertain current or historical affiliations.

Reproduction: `python3 scripts/sanitize-lehigh-rowan-intakes.py --batch lehigh --check` and `--batch rowan --check`. Each checks the retained output receipt before parsing assertions and compares both output files byte for byte. `python3 -m unittest discover -s test/sourceqa -p test_lehigh_rowan_intakes.py -v` passed four focused checks. No network requests were made and no supplied research scripts were executed. The source assertions are not an independent verification of the original researchers' findings.
