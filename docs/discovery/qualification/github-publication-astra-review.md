[GitHub rate documentation](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) permits anonymous public-data access subject to the originating IP's limit and secondary controls. This supports separate factual metadata review; no general full-text grant is inferred.
