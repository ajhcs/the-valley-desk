## What may be retained and used

The two native Crossref work-list responses are provider-selected factual metadata:
DOI, title, authors, publication date, publisher and related factual fields. The
request itself excludes abstracts, rather than stripping an existing response and
calling it original. Independent whole-payload field/URI review preceded portable
copying. [Crossref's policy](https://www.crossref.org/documentation/retrieve-metadata/)
distinguishes reusable bibliographic facts from separately copyrighted abstracts.

QSIPrep's repository license is BSD-3-Clause. CaPTk has component-specific terms,
including a noncommercial exception, so a blanket permissive-license claim would
be wrong. Neither software license grants article, third-party website, logo or
contact-data rights. Article-specific abstract/full-text reuse remains on hold;
Springer TDM URLs and PMC availability do not establish CC BY permission.

## Raw-retention correction

Independent actual-D1 probes found that ignored contact fields could persist in
GitHub/Crossref raw representations, and Crossref could retain abstract text in
its metadata-only scope. The correction strictly decodes the whole JSON payload
before projection, rejects duplicate decoded keys and unsupported numeric/Unicode
forms, and checks known contact/credential indicators in all values and keys.
Crossref abstract/full-text payloads are withheld. Bounded URI/entity decoding
closes demonstrated encoding bypasses. An exact canonical repository SSH URL is
allowed only on validated, route-known repository records; null credential slots
remain supported while nonnull clone tokens fail. Fixed errors omit source text.

These are bounded material guards and independently tested retention boundaries,
not a universal sensitive-prose classifier or copyright adjudicator. Source-specific
permission and whole-payload review remain required. The exact four native bodies
also pass the corrected guard; offline D1 replay uses separately identified synthetic
authority. The acquisition-time and final helper hashes are recorded separately.
