# WP13 — Sol implementation handoff

Disposition: bounded local implementation ready for independent qualification. Root owns package acceptance. No real source access, retention rights, enrollment, collection or deployment is established by this increment.

The adapter supports one explicit source-specific HTML5 extraction contract: reviewed class tokens identify public professional, institution/lab/association profile cards or publication cards; each card has a literal source-native HTML ID. Field text must come from a unique visible leaf element. Source dates must be literal matching `<time datetime>` values, with year/month/day precision preserved. Exact original HTML excerpts and string offsets remain inspectable. This is a restricted passive HTML subset, not a universal directory, feed or institution parser.

## Qualified scope and retained boundaries

`qualifyDiscoveryInstitutionalScope` freezes and hashes the exact endpoint template, source family, record kind, class map, provenance proposals, profile-date window, roster denominator and all page/item caps. It grants no access authority. `createDiscoveryInstitutionalAdapter` composes the accepted WP06 source/issued-plan/transport and WP07 raw representation/page/claim/chain seams. It adds no persistence authority or catalog write path.

The public methods are `plan`, `inspect`, `parser`/`parse`, `replay`, `nextPage` and `distinctReviewedOriginCount`. Initial requests use the reviewed `page=1`; continuation requires a literal declared next link to the already qualified exact endpoint, a sequential page parameter and authenticated retained ancestry. A source cannot extend its origin, endpoint, fixed parameters or cap by supplying a link. Declared feed and directory links remain inert proposals; feeds are not fetched or parsed, paths are not guessed, and no whole-site crawl is performed.

Original response bytes can be retained only after the parser passes a whole-response privacy/structure check. That check rejects known contact-email/phone forms in raw or decoded text and attributes, including split text and bounded URL escaping. Scripts, styles, templates, hidden/inert attributes, forms, foreign namespaces, comments, unknown attributes and unsupported elements fail before any per-record catch. Link semantics are restricted to declared RSS/Atom alternates and next links; stylesheet and other unsupported links fail. Meta content is restricted to UTF-8 charset or an exact viewport literal. Source templates have no fixed query fields; observed href/text URLs must be query-free except for the registered exact endpoint with a literal numeric `?page=N` within its reviewed range. Secret-bearing queries and all URL fragments are rejected in the original response, never stripped while retaining the old bytes. Nonempty HTTP Link response metadata is unsupported and rejected in both active parsing and retained replay. Attribute and visible text checks apply to unmapped material too. The passive subset deliberately rejects ordinary complex pages; it does not claim universal detection of private information expressed in arbitrary prose. Actual source qualification must review public-only content and permission/rights separately. A malformed semantic record may produce a gap only after the entire response passes this boundary.

## Candidate and evidence semantics

A person or organization can be a private creator-first lead without a repository, paper or other indexed artifact. Literal professional health-tech basis, profile date, affiliation unit, county, location role and dates remain separate evidence proposals. `currentLocalSupported` is an inspection-only assessment of the mapped source declarations; metadata always states `assessmentOnly: true`, `currentEmploymentConfirmed: false` and `publicationAuthorized: false`. Human regional admission and truth validation are not implemented.

Only literal `actual-unit` location evidence and an exact accepted `PA:*`/`NJ:*` county key can support the local assessment. Headquarters, residence, service area and an actual unit outside the nine counties cannot substitute. Start/end/current-through precision is retained; expired declarations remain historic, missing expiry remains unknown, and conflicting dates remain contradictory. A profile-date outside the reviewed window is retained with a hold. Textual professional basis is retained for review rather than inferred from organization reputation.

Creator, publisher and adopter relationships are separate typed proposals with unresolved target identities. A publisher or adopting local hospital is not promoted to creator. Public ORCID/ROR links are unverified identity proposals with no network request or person merge. Matching names and mirrored prose have no equivalence authority.

The source-native key includes the canonical full requested endpoint, its numeric directory page and the card ID. HTML IDs are document-local: a repeated card ID on another page produces a separate unresolved native lead. A page move is not inferred to be a person match. A configured `originUrl`, `provenanceOriginId` or `originReview` is explicitly unresolved and cannot coalesce native people. `distinctReviewedOriginCount` delegates supplied retained evidence references to the existing genuine WP05 ledger resolver; it has no text-equality or caller-count fallback. Source versions hash source values and dates, excluding HTML position, raw excerpt formatting and clock-derived assessment.

## Synthetic coverage and limits

The retained fixtures under `test/fixtures/discovery-sources/institutional/` cover an independent professional without an artifact; association publisher/creator/adopter separation; local headquarters with an out-of-region actual unit; historic and unknown-expiry biographies; two directory pages; a declared off-scope continuation; an off-host feed proposal; and an encoded contact outside mapped records. `scope.json` is a fictional extraction contract, not a source qualification receipt.

A directory is complete only when its declared terminal traversal and explicit reviewed roster total agree, with no rejected records, privacy/structure failure or cap. Unknown totals, missing rows, off-scope next links, rejection and caps remain coverage gaps. Duplicate IDs within one document fail as ambiguous structure; repeated IDs on different pages remain distinct unresolved leads. A completed collection round does not establish source recall. Refresh and identity-review costs are explicit illustrative per-record estimates, not measured operational labor.

AC-WP13-01/02/03/04/05 are represented by the synthetic profile/output/location/date/navigation/privacy cases. AC-WP13-06 requires actual D1 retained ancestry and reviewed origin-ledger challenges in Terra's independent suite; passing those software experiments does not establish a real directory denominator or mirror equivalence. There are no actual source access receipts, real profiles, live roster measurements or empirical E04/E01–E06 results in this handoff.
