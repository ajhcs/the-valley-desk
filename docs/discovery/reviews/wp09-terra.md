# WP09 independent review — Terra

Review uses synthetic evidence and provider responses only. Actual local D1 starts empty with migrations 0001–0044, `envFiles: []`, `persist: false`, `remoteBindings: false` and closed injected egress. Qualification, search and fetch do not contact PubMed or establish real-world identity, location, source access or recall. The test uses the actual WP06/WP07 registry, transport, retained representation, receipt and private-lead boundaries; it does not manufacture a public SourcePage.

The legacy Wistar plan remains bounded and rejects a different institution, excess page size, offset or window and a cloned scope. The generalized synthetic scope independently binds a first-party hash-verified quote, institution, search literal and regional evidence. Search produces a retained incomplete receipt; a separately qualified fetch binds the ordered requested PMIDs to that receipt and commits a paper-only private lead. An exhausted metadata budget makes no fetch and leaves incomplete health; a restarted adapter requalifies the same evidence and resumes the same deterministic fetch source only after an explicit new source revision, budget window and collection cohort. The old budget stays charged.

Adversarial cases cover malformed and repeated search PMIDs, short and mismatched result pages, changed query, offset and fetch IDs, missing/unrequested/duplicate PMIDs, missing or corrupt retained search parents, XML entities and foreign namespace, duplicate unresolved authors, publication-bound affiliation with current employment unknown, year/month precision, email redaction in titles, names and affiliations, and changed correction metadata producing a new version. Normalized author/affiliation metadata remains provisional and recoverable from retained source bytes; it is not an admitted person or current employment claim. Provider wide E-utilities rate and operating rules remain a live-access qualification concern; [NCBI guidance](https://www.ncbi.nlm.nih.gov/books/NBK25497/) describes request-rate limits.

Earlier runs and failures remain under `.discovery-work/wp09-terra/`. The initial deterministic-binding test failed on a fixture lease-ID conflict after WP07's source-unique lease rule; the revised test reuses the fenced lease correctly. Test results and frozen input hashes are recorded separately after final adapter stabilization.
