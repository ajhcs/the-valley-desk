# Independent metadata-and-link pilot review

16 November 2026. Astra reviewed EX28's active amendment, retained-field selection,
offline builder, DTO, query/API, Worker integration and rendered local pilot.
This is independent software and source-trace review, not independent human
benchmark annotation or authorization to publish the pilot.

## Scope and disposition

The MP00 amendment is coherent: the finite factual metadata/link preview can
proceed without making optional full-text reuse or WP03 benchmark completion
universal prerequisites. The original automated admission contracts and empirical
thresholds remain unchanged. Fourteen listings represent six repositories, six
publications and two organization background records, not fourteen independent
projects or reference cases. Only two separately evidenced repository-to-publication
citation edges are projected. No reciprocal or historical identity-continuity
claim is inferred.

The exercised implementation has no remaining blocking finding. The final receipt
review below confirms full local qualification; delivered-head CI remains the
orchestrator's separate handoff evidence. Deployment is not authorized; MP04
remains held.

## Findings resolved during review

The original builder accepted a genuine but semantically wrong field: substituting
QSIPrep's `/owner/id` for `/id` produced `github:61955309` as its repository
identity instead of actual repository `156589095`. Matching a retained value and
hash alone did not establish that value's role. The corrected builder requires
provider-specific semantic pointers, binds request URLs and native identities,
and rejects the reproduced substitution. Title/date substitutions and mismatched
Crossref roots are also rejected. A deep input snapshot taken before asynchronous
reads keeps the projection and selection digest bound to the same input.

The UI heading now says publication-reported affiliations, preserving records
that name only an institution without implying a city. Authors are explicitly a
selected subset; repository owner accounts remain distinct. The GitHub API terms
link now points to the official Terms of Service, section H.

## Independent evidence

All fourteen selected native body hashes and the derived observation hash match
their retained files. All 107 selected JSON-pointer values match those bytes.
The generated catalog rebuilds exactly. Selected output omits contacts, abstracts,
README/article/code bodies, raw observation flags, ORCID authentication flags and
workspace paths. Source-use review checked official Crossref metadata guidance,
GitHub API terms and ROR's CC0 metadata basis; this narrow basis does not license
linked software or article content. No additional source collection occurred.

Fifteen independent Node test groups passed: twelve builder/schema/query/API/page
groups and three assembled Worker/build-output groups. They cover wrong semantic
fields, request/provider/hash/value drift, reversed or mismatched citation edges,
duplicate relations, caller mutation during awaits, duplicate JSON keys, invalid
Unicode/nonfinite/deep input, inherited or ambiguous pointer selectors, unsafe
URLs/private DTO fields, deterministic filtering and sorting, partial-date
preservation, unknown dates last, exact flag handling, disabled catalog-loader
nonuse, HEAD/405 behavior, fixed error diagnostics, and page fallback output.
Canonical pilot routes did not touch D1 or external fetches. Nine encoded or
near-route variants returned 404 without pilot data under both feature states.

private evidence paths; the shared schema code is present as expected.
The fifteen groups were rerun successfully after Sol's final source freeze;
all twelve hashes in `reviewed-input-sha256.json` matched the reviewed files.

## Limits

The collection remains finite, development-exposed and dated. Historical
affiliations do not establish current employment, a person's actual work site,
software authorship or local creation. No regional completeness, clinical
effectiveness or measured discovery accuracy is established. The actual strict
WP03 corpus and human labels are unchanged. This review does not accept WP14,
complete WP12/WP13, activate collection, or authorize deployment. Other browsers,
broader accessibility testing and future source/field expansions remain outside
the exercised local preview.
